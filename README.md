# Astro-Capybara-Fact-Machine
A cute, interactive capybara that tells you fun facts about astronomy when you click on it!

This is just a fun project inspired from my interest in astronomy and my favorite animal, the capybara! There are currently 25 facts in circulation. I might add to my personal website later!
